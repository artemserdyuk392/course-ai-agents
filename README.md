# AI-агенты и мультиагентные системы

Учебный курс, охватывающий теорию и практику разработки интеллектуальных агентов — от классических архитектур до современных LLM-оркестраторов.

## Содержание

### Лекции (8 штук)
1. Введение в AI-агенты: определение, история, таксономия
2. Архитектура интеллектуальных агентов: BDI, sense-plan-act
3. Обучение агентов: RL, reward shaping, PPO
4. Мультиагентные системы: протоколы, FIPA, KQML
5. Координация и кооперация: теория игр, аукционы, Contract Net
6. LLM-агенты: ReAct, tool use, CoT, RAG, planning
7. Мультиагентные оркестраторы: CrewAI, AutoGen, LangGraph
8. Практические аспекты: безопасность, guardrails, HITL

### Практические задания
К каждой лекции — набор из 20+ заданий нарастающей сложности.

### Итоговый тест
30+ вопросов разных типов: одиночный выбор, множественный выбор, ввод ответа, сопоставление, упорядочивание.

## Технологии

- HTML + CSS + vanilla JavaScript
- Без фреймворков и сборки
- SPA с hash-роутингом
- Тёмная/светлая тема
- Адаптивный дизайн

## Запуск локально

Открыть `index.html` в браузере или запустить локальный сервер:

```bash
python3 -m http.server 8000
```
